# Portfólio MS Software

Site portfólio profissional de Matheus Ferreira de Souza, Desenvolvedor Full Stack PJ/MEI na MS Software. O projeto apresenta experiência profissional, habilidades técnicas, serviços, projetos, certificações e canais de contato em uma interface moderna, responsiva e com suporte a tema claro/escuro.

## Visão Geral

Este portfólio foi desenvolvido para fortalecer a presença online profissional, transmitir credibilidade para empresas, recrutadores e clientes, e centralizar informações relevantes sobre atuação técnica, projetos e serviços oferecidos.

## Funcionalidades

- Layout responsivo para desktop, tablet e smartphone.
- Tema claro e escuro com preferência salva no navegador.
- Menu de navegação por seções.
- Seção de habilidades técnicas com descrições recolhíveis.
- Linha do tempo profissional com experiências expansíveis.
- Galeria de projetos e certificações.
- Formulário de contato via e-mail.
- Links para GitHub, LinkedIn, WhatsApp, Instagram e e-mail.
- Estrutura HTML semântica com melhorias de acessibilidade.
- Metadados básicos para SEO e compartilhamento.

## Como Executar Localmente

Por ser um site estático, basta abrir o arquivo `index.html` no navegador. Para testar com servidor local:

```bash
python -m http.server 4174
```

Depois acesse:

```text
http://127.0.0.1:4174
```

## Deploy

O projeto pode ser publicado facilmente em plataformas de hospedagem estática, como:

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages

Configuração recomendada para deploy:

- Branch de produção: `main`
- Diretório de publicação: raiz do projeto
- Build command: não necessário
- Output directory: não necessário
